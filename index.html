Sổ điểm danh 12A6

Bản trên GitHub chưa có file mới (xuất Excel tuần/tháng, quay tuần trước).

Cách cập nhật (điện thoại):

  1. Tải file index.html từ Grok (tin nhắn có nút tải).
  2. Vào github.com/khanhgf091/so-12a6
  3. Bấm file index.html → menu … → Delete file → Commit
  4. Add file → Upload files → chọn file vừa tải → Commit
  5. Đợi 1 phút, mở lại khanhgf091.github.io/so-12a6

Kênh tự động không gửi được file ~80KB một lần; cần Upload tay một lần.
